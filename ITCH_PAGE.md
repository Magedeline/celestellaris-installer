Title: Celestellaris
Kind of project: Game mod / Tool (Downloadable)
Short description: A big Celeste mod, with a one-click installer.
Classification: Games, Platforms: Windows

Body:
Celestellaris is a fan-made mod for Celeste. You need your own copy of Celeste (Steam, Epic, GOG or itch).

How to install
1. Download and extract the zip.
2. Run Install-Celestellaris.exe. It finds Celeste, installs the Everest mod loader if needed and
   downloads the required helper mods, checking every download against a published checksum.
3. Start Celeste.

Safety: the installer is open source (https://github.com/Magedeline/celestellaris-installer),
collects no data, and its SHA-256 is listed on the release page. Free code signing provided by
SignPath.io, certificate by SignPath Foundation (once approved).

Celeste is made by Maddy Makes Games. This mod is not affiliated with or endorsed by them.
